# 简繁转换 · 香港 / 台湾

一个只做中文简繁转换的 VS Code 插件，基于 OpenCC-JS 1.4.2 地区词库。支持编辑器选区、全文和直接转换磁盘大文件，转换过程完全离线。

香港字形和台湾字形分别提供，台湾地区用语转换另有独立选项。

## 安装与使用

需要 VS Code 1.85 或更新版本。

1. 在扩展面板右上角的 `…` 菜单中选择 **从 VSIX 安装…**。
2. 选择构建生成的 `chinese-conv-a.b.c.vsix`。
3. 打开文本文件，按 `⌘⇧P`（Windows/Linux 为 `Ctrl+Shift+P`），搜索 **简繁转换**。

也可以在终端执行：

```sh
code --install-extension chinese-conv-a.b.c.vsix
```

当前 `publisher` 为本地打包使用的占位名 `zgia`，尚未发布到 Marketplace。

### 编辑器文本

选中文字后，右键 **简繁转换**，直接点击 **简体 → 香港繁体** 等六个转换方向，即可转换选区，无需再次选择方向。没有选中文字时，这六项置灰。菜单底部用分隔线隔开 **转换全文…**，点击后选择方向，始终转换整篇文档，即使当前有选区。

命令面板仍提供 **简繁转换: 转换选区或全文…** 和六个独立方向命令，便于自行绑定快捷键。以下自动判断选区或全文的规则适用于这些命令面板入口：

- 有非空选区时，只转换选中的文字，支持多选区；重叠选区合并，空光标忽略。
- 没有选中文字时，转换整个文档，无须先全选。
- 转换结果作为一次编辑应用，可用一次撤销恢复；插件不会自动保存文档。
- 转换期间可以取消。如果内容在转换期间改变，插件会放弃应用结果并提示重试，避免覆盖刚输入的内容。

选区边界也是词组判断的边界。需要准确转换完整词语时，请选中完整词语或转换全文。

### 磁盘大文件

执行 **简繁转换: 转换磁盘文件（另存为）…**，选择输入文件、转换方向和输出路径；也可以在文件资源管理器中右键文件。

文件不必先在编辑器中打开。转换在后台线程中流式读取、写入，进度通知支持取消。结果另存为新文件，例如 `content.s2hk.txt`，已有文件和原文件不会被覆盖。只有转换成功后才生成完整的输出文件；取消或失败会清理临时文件。源文件有未保存的编辑器修改时，需要先保存再执行磁盘转换。

该入口支持 **UTF-8 文本**，保留原有 UTF-8 BOM、CRLF/LF 换行和空白。GBK、Big5、UTF-16 等文件应先用正确编码打开并另存为 UTF-8；无效 UTF-8 或包含 NUL 字符的文件会拒绝转换。

为防止分块切断词组，转换只在词库验证过的安全分隔符处切分。内存需求因此取决于最长的无安全分隔符片段；连续且没有安全分隔符的超长文本仍需缓存整个片段。编辑器全文替换还受 VS Code 文档与撤销记录的内存开销影响，极大文件建议使用磁盘转换命令。

## 转换方向

| 模式    | 命令                          | 行为                                                      |
| ------- | ----------------------------- | --------------------------------------------------------- |
| `s2hk`  | 简体 → 香港繁体               | 香港字形，如 `系統`、`裏面`、`衞生`、`軟件`               |
| `s2tw`  | 简体 → 台湾繁体（字形）       | 台湾字形，如 `裡面`、`後臺`，保留原有词汇                 |
| `s2twp` | 简体 → 台湾繁体（含台湾用语） | 同时转换常见地区用语，如 `軟體`、`滑鼠`、`網路`           |
| `hk2s`  | 香港繁体 → 简体               | 香港繁体字形转简体                                        |
| `tw2s`  | 台湾繁体 → 简体               | 台湾繁体字形转简体，保留原有词汇                          |
| `tw2sp` | 台湾繁体 → 简体（含大陆用语） | 同时将 `軟體`、`滑鼠`、`網路` 转为 `软件`、`鼠标`、`网络` |

例如：

| 原文                           | 香港繁体                       | 台湾繁体（字形）               | 台湾繁体（含台湾用语）         |
| ------------------------------ | ------------------------------ | ------------------------------ | ------------------------------ |
| `系统里面的软件、鼠标、网络。` | `系統裏面的軟件、鼠標、網絡。` | `系統裡面的軟件、鼠標、網絡。` | `系統裡面的軟體、滑鼠、網路。` |
| `海内存知己，天涯若比邻。`     | `海內存知己，天涯若比鄰。`     | `海內存知己，天涯若比鄰。`     | `海內存知己，天涯若比鄰。`     |

台湾用语转换能区分 `海内存知己` 和电脑的 `内存`：后者在合适上下文中转换为 `記憶體`。转换依据 OpenCC 词组词库，并非逐字替换或语言模型；专名、行业术语和有歧义的句子仍可能需要人工复核。繁简映射也不保证双向无损。

## 开发与打包

使用 Node.js 20 或更新版本：

```sh
npm ci
npm run check
npm test
npm run build
```

可使用本机 VS Code 运行编辑器集成测试（临时隔离配置，不使用现有插件与设置）：

```sh
npm run test:vscode
```

macOS 默认寻找 `/Applications/Visual Studio Code.app`；其他安装位置可通过 `VSCODE_EXECUTABLE` 指定 VS Code 可执行文件。大文件性能与内容校验可用 `npm run benchmark -- 100` 运行，参数单位为 MiB，测试数据会自动清理。本机约 100 MiB 的含中文、emoji、CRLF 文本转换为台湾用语耗时约 3 秒；实际耗时取决于设备与内容。

在 VS Code 中打开本目录后按 **F5**，选择“调试简繁转换插件”。启动前会检查类型并构建，在新开的“扩展开发宿主”窗口中测试命令。修改代码后可重新启动调试，或运行 `npm run watch` 持续构建。

打包需要本机已有 `@vscode/vsce`，或先全局安装该工具。它未列入项目开发依赖：

```sh
npm install --global @vscode/vsce
npm run package
```

生成的 VSIX 包含转换词库与后台线程，无需额外安装 OpenCC、Python 或原生模块；安装后运行转换无需网络。打包流程会先运行类型检查及构建。
